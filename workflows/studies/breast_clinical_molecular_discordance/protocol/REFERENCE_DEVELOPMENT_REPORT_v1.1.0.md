# Reference-development protocol 1.1.0

## Amendment decision

Founder decision `1.1.0` authorizes the outcome-blind input-scale and ER-selection
amendment. Protocol `1.1.0` prospectively supersedes the candidate transformation
in protocol `1.0.0`; the original remains immutable history. GSE81538 remains a
reference-development candidate rather than a locked classifier component.

## Input representation

Matrix-audit receipt `1.0.0`, generated by frozen revision `cf8d7f6`, verified
all 7,614,810 measurements and the `log2(0.1)` floor. The stored
`log2(FPKM + 0.1)` values will therefore be consumed unchanged. The earlier
conditional `log2(FPKM + 1)` proposal is rejected; applying another logarithm
would distort the source data.

## ER subset rule

Only public `er consensus` code `0` is eligible for the ER-negative stratum and
code `3` for the ER-positive stratum. Codes `1` and `2` are excluded. Eligible
accessions are sorted lexicographically within strata and the first 50 per stratum
are selected before expression parsing. The exact identifier manifest remains
outside Git.

The source paper documents three independent pathology readings and a majority
consensus, but the public metadata does not include an inline codebook for the
four codes. Treating `0` and `3` as extreme categories is a founder-approved,
conservative inference and remains a visible limitation.

## Remaining lock requirements

1. Execute the field-isolated metadata parser and freeze the exact external
   100-sample manifest.
2. Construct the gene-wise median reference and execute the prespecified
   outcome-blind reference sensitivities.
3. Preserve prospective technical-error calibration as a separate unresolved
   dependency.

No classifier, subtype, outcome, threshold, clinical result, publication, or
submission is authorized by this amendment.
