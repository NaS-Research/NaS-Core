# NAS-BRCA-002 Research Path Decision Memo 1.0.0

The current study cannot truthfully finish its intended independently calibrated
reliability claim using public data alone. Synthetic tests validate software, and
the excluded public replicate sources establish feasibility, but neither provides
the target-assay technical-error distribution or independent threshold calibration
required by the frozen question.

## Path A — preserve the current study

Continue the independently calibrated reliability and abstention framework. This
preserves the research question and offers the strongest contribution if completed.
It necessarily requires bounded provider due diligence, a lawful specimen pathway,
laboratory work, and funding. The immediate next action would be one eligibility
inquiry to CHTN; it would not authorize an application, quote acceptance, purchase,
or specimen receipt.

## Path B — public-data-only redesign

Replace the current question with continuous PAM50 uncertainty and cross-cohort
transport characterization. TCGA-BRCA and GSE96058 could support fixed-reference
score margins, quality failures, descriptive technical-replicate sensitivity,
transport degradation, and explicit null findings. The paper could not claim a
validated reliability state or abstention threshold. This is a material scope
change requiring a new question, novelty boundary, protocol, preregistration, and
manuscript framing.

## Path C — prohibited shortcut

Continuing the current reliability claim while silently treating excluded public
replicates or synthetic perturbations as target-assay calibration would be
scientifically invalid and is prohibited.

The recommendation is Path A if NaS intends to make the stronger reliability
contribution. Path B is appropriate only if the no-contact, no-spending, and
no-specimen constraints are intended to remain permanent.
