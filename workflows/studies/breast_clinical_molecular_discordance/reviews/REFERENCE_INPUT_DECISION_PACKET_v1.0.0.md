# NAS-BRCA-002 reference-input scientific decision packet 1.0.0

Status: **founder decision required**

This packet proposes two bounded Phase 1 method decisions. It does not authorize
reference construction, classifier execution, outcome access, external contact,
clinical use, publication, or submission.

## Decision 1 — processed-expression transformation

### Evidence

GSE81538 matrix-audit receipt `1.0.0`, generated by frozen revision `cf8d7f6`,
parsed all 7,614,810 measurements and observed:

- minimum `-3.32192809488736`;
- 969,918 measurements at that floor;
- zero values below the floor; and
- zero missing or nonfinite values.

The expected mathematical floor is `log2(0.1) = -3.321928094887362`. Official
GEO sample processing metadata states that `0.1` FPKM was added before log2
transformation. The matrix receipt SHA-256 is
`98bfb62ad4ba1247feb0ba6c1487341517bb59049c2ad22b4e51fe2ed2773b4c`.

### Recommendation

Consume the stored matrix unchanged as `log2(FPKM + 0.1)`. Do not apply the
protocol `1.0.0` candidate operation `log2(FPKM + 1)`, because a second logarithm
would distort already-transformed values. Preserve protocol `1.0.0` as immutable
history and issue protocol amendment `1.1.0` prospectively.

## Decision 2 — ER-balanced subset eligibility

### Evidence

The checksum-bound GSE81538 family SOFT object contains 405 complete
`er consensus` fields:

| Consensus code | Records |
|---:|---:|
| 0 | 82 |
| 1 | 8 |
| 2 | 11 |
| 3 | 304 |

The primary article states that diagnostic and newly stained slides were each
scored independently by three pathologists using a 1% hormone-receptor positivity
threshold, and that the final biomarker consensus used majority scores. The public
metadata does not contain an explicit inline codebook defining codes `0–3`; the
interpretation of extreme codes as unambiguous negative/positive is therefore a
conservative inference, not a quoted source definition.

### Recommendation

For reference selection only:

- map consensus code `0` to the eligible ER-negative stratum;
- map consensus code `3` to the eligible ER-positive stratum;
- exclude codes `1` and `2` as non-extreme or discordant; and
- sort eligible GEO accessions lexicographically within each stratum and take the
  first 50, exactly as protocol `1.0.0` prespecified.

This rule retains 82 eligible ER-negative and 304 eligible ER-positive records,
so both 50-sample strata are feasible. It is deliberately more conservative than
mapping intermediate categories and prevents ambiguous receptor evidence from
choosing the centering reference.

## Independent-cohort boundary

The primary article describes the 405-tumor GSE81538 set as the training cohort
and the 3,273-tumor GSE96058 set as an independent prospective validation cohort.
That publication-level statement supports cohort-role separation but does not
prove identifier-level or biological-specimen non-overlap. The later receipt must
retain that limitation. No GSE96058 molecular value or outcome may be accessed
during reference development.

## Data handling after approval

The deterministic field-isolated parser will read only:

- `!Sample_title`;
- `!Sample_geo_accession`; and
- `er consensus`.

The exact 100-record selection manifest will be stored immutably in the governed
Seagate object store. Git will retain only aggregate counts, the manifest object
key, byte length, checksum, algorithm, provenance, and limitations. No participant
identifier, molecular row, outcome, or treatment field will be committed or sent
to a generative model.
